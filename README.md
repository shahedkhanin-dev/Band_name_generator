# 🎸 Band Name Generator

A fun and interactive Python script that helps you come up with creative band names based on your personal inputs. The program asks for the city you grew up in and your pet’s name, then combines them to generate a quirky band name suggestion.

## ✨ Features
* **Simple command-line interface**
* **Input validation** to ensure users don’t skip questions
* **Readable and beginner-friendly code** using f-strings
* **Great starter project** for learning Python basics like loops, conditionals, and user input

## 🚀 How to Run
1. **Clone the repository**
2. **Run the script** with:
   ```bash
   python band_name_generator.py
   ```
3. **Answer the prompts** and get your personalized band name!
